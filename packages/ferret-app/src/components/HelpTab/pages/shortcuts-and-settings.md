## Shortcuts and settings

### Keyboard shortcuts

On a Mac, use **Cmd** where this table says **Ctrl**. You can change any of them in **Preferences → Keybindings**.

| Shortcut | Action |
| --- | --- |
| **Ctrl+Enter** | Send the request |
| **Ctrl+S** | Save |
| **Ctrl+Shift+S** | Save all tabs |
| **Ctrl+N** | New request |
| **Ctrl+O** | Import a collection |
| **Ctrl+E** | Edit environments |
| **Ctrl+K** | Search collections and requests |
| **Ctrl+F** | Search the sidebar |
| **Ctrl+D** | Clone the selected item |
| **Ctrl+R** | Rename the selected item |
| **Ctrl+W** | Close the tab |
| **Ctrl+Shift+T** | Reopen the last closed tab |
| **Ctrl+1 … Ctrl+8**, **Ctrl+9** | Go to a tab by position, or to the last tab |
| **Ctrl+J** | Switch between side-by-side and stacked panes |
| **Ctrl+\\** | Collapse or show the sidebar |
| **Ctrl+T** | Open a terminal in the collection folder |
| **Ctrl+,** | Open Preferences |
| **Ctrl+=**, **Ctrl+-**, **Ctrl+0** | Zoom in, zoom out, reset zoom |

### Preferences

Open them with the gear in the status bar or **Ctrl+,**.

| Tab | What you can change |
| --- | --- |
| **General** | SSL certificate verification and custom CA certificates, cookie handling, **Auto Save**, request history, request timeout and the default folder for new collections. |
| **Themes** | The color theme. Light and dark teal and azure themes are the defaults, and there are many more. |
| **Display** | Fonts, zoom, and which sidebar sections are shown. |
| **Proxy** | Send requests through a proxy, or follow the system's proxy settings. |
| **Client Certificates** | Certificates for servers that require mutual TLS. |
| **Keybindings** | Change or reset the shortcuts above. |
| **Cache** | Local caches that speed up opening large collections. |
| **Support** | Links to the documentation and issue tracker, **Check for updates**, and the **Third-party notices** (the licenses of the open-source software Ferret includes). |
| **Beta** | Features that are still being tested, such as the mock server. |

### Updates

Ferret never updates itself or contacts a server in the background. To look for a new version, open **Preferences → Support → Check for updates**. A dialog explains that one request will go to GitHub to read the list of releases, and nothing happens unless you press **Yes, check**. If there is a newer version, you can open its page in your browser and download it yourself.

### Where your data lives

- **Collections** are folders wherever you created them. Reveal one from its **…** menu.
- **Preferences, cookies and history** are stored in Ferret's own data folder on your computer.
- **Nothing is stored online.**
